Container release06 / 12
Release identity

One directory per release

directoryName

YYYY.MM.N-<full-sha> recorded in release.json. The same name is the artifact release-<version>-<sha>.

current symlink

CD points /opt/platform/current at that directory after checksums.txt matches. Rollback points it back.

Node.js on the host reads current/web and current/api. PostgreSQL stays where it already is.

Immutable identity07 / 12
