Container release06 / 15
Release identity

Two digests per image

GHCR reference

name@sha256:… — registry manifest digest. Used to pull on the runner and recorded in release.json.

imageId / RootFS

Local config digest after build/pull. After offline docker load, Compose runs by the loaded Id; transfer proves RootFS.Layers match.

Release Compose keeps ${WEB_IMAGE} / ${API_IMAGE} placeholders. Runtime Ids land in runtime-images.env.

Monitor data path11 / 15
Staging network

Egress + DNS for GitHub

backend (internal)

Web ↔ API ↔ PostgreSQL. No outbound internet — keeps the database private.

egress + extra_hosts

API reaches api.github.com. CD pins the hostname via compose.egress.yml (extra_hosts + public DNS) because dual-homed containers often fail DNS (EAI_AGAIN / bad address).

Deploy probes https://api.github.com/zen from the API container before smoke tests.
